ABOUT RAG PIPELINES
RAG stands for Retrieval-Augmented Generation. It is a technique where an LLM
is given relevant documents as context before generating an answer. This prevents
hallucination and keeps answers grounded in real facts.

The RAG pipeline has two phases:
Indexing phase: Load documents, split into chunks, embed using an embedding model,
store vectors in a vector database like ChromaDB or Pinecone.

Query phase: Embed the user question, find similar chunks using cosine similarity,
inject top chunks into the LLM prompt, generate a grounded answer.

ABOUT LANGCHAIN
LangChain is a Python framework that provides ready-made components for building
LLM-powered applications. Key components include document loaders, text splitters,
embedding wrappers, vector store integrations, and chain abstractions.

ABOUT LANGGRAPH
LangGraph extends LangChain for building agentic workflows modelled as directed graphs.
Nodes represent LLM calls or tool invocations. Edges represent transitions between steps.
LangGraph supports cycles, branching, multi-agent coordination, and state checkpointing.
